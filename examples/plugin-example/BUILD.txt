# ExamplePlugin（Stage3 + 插件 UI 槽合并示例，2.0）

示例插件已合并原 SettingsZoneDemoPlugin 功能：
- 模式：示例插件模式（候选固定串 `Hello from Plugin`）；无附加按钮（第 4/6 格隐藏）；
- 菜单：主窗/托盘/悬浮球各一项"关于插件"；
- 六窗口按钮区各注册一个"注意"按钮（主窗/设置/配置名单/方案管理/数字设置/座位设置），
  点击弹出"无运行中热插拔：增删插件/改按钮都要重启"并写日志 `DEMO_BUTTON_CLICKED`。

## 编译与打包（以主 jar 或主工程 out 为 API 类路径）

插件 jar 只允许包含插件自身类，禁止包含 `com/randomnamepicker/**`（API 由宿主 parent-first 提供）。

```
javac -encoding UTF-8 -cp <主 jar 或 out 目录> -d build ExamplePlugin.java
jar cf ExamplePlugin.jar -C build .
```

仓库内示例：

```
javac -encoding UTF-8 -cp ../../out -d build ExamplePlugin.java
jar cf ExamplePlugin.jar -C build .
```

## 安装 / 卸载
- 安装：把 `ExamplePlugin.jar` 复制到程序运行目录 `plugins/`，重启程序。
- 卸载：删除该 jar 后重启（不做运行中热插拔）。

## 预期效果
- 主窗"插件"菜单：关于插件 + 只读"ExamplePlugin 2.0"；模式下拉框出现"示例插件模式"，抽取定格 `Hello from Plugin`；
- 主窗 3×2 功能按钮下方出现"插件"标识 + 分隔线，其下两列按钮区含"注意"；
- 打开 设置/配置名单/方案管理/数字设置/座位设置：各出现"插件"面板与"注意"按钮；
- 点击任一处"注意" → 弹窗"无运行中热插拔：增删插件/改按钮都要重启"，日志记 `DEMO_BUTTON_CLICKED`；
- 退出程序日志记 `PLUGIN_UNLOADED`。
