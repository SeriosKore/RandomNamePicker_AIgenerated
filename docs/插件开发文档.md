# 插件开发文档（v1.1.0）

> 教程目标：从零开发一个 RandomNamePicker 插件，不改动主程序一行代码。
> 前置阅读：《插件接口文档.md》（全部 API 说明）。
> 完整示例源码见仓库 `examples/MultiBallPlugin/` 与 `examples/PenPlugin/`。

## 1. 环境准备

- JDK 8+（推荐 17/22），并配置 PATH；
- 主程序产物 `RandomNamePicker.jar`（在项目根目录运行 `build.bat` 生成）。

## 2. 快速上手（5 分钟示例）

**第 1 步：编写插件类**

```java
import javax.swing.*;

public class HelloPlugin implements Plugin {

    public String getName() { return "你好插件"; }
    public String getVersion() { return "1.0.0"; }
    public String getDescription() { return "最小插件示例"; }

    public void onLoad(PluginContext context) {
        // 注册主窗口“插件”菜单项
        context.registerMainMenuItem("打招呼", () ->
            JOptionPane.showMessageDialog(null, "你好，世界！"));

        // 注册悬浮球右键菜单项
        context.registerFloatingBallMenuItem("打招呼", () ->
            JOptionPane.showMessageDialog(null, "来自悬浮球的问候！"));
    }

    public void onUnload() { }
}
```

**第 2 步：打包（关键：清单属性）**

```bat
javac -encoding UTF-8 -cp RandomNamePicker.jar -d classes HelloPlugin.java
echo Plugin-Class: HelloPlugin> manifest.txt
jar cfm HelloPlugin.jar manifest.txt -C classes .
```

**第 3 步：部署**

把 `HelloPlugin.jar` 放入程序运行目录的 `extensions/` 文件夹，启动程序即自动加载。

## 3. 完整插件工程规范（以 MultiBallPlugin 为例）

```
examples/MultiBallPlugin/
├── MultiBallPlugin.java        # 插件入口（实现 Plugin）
├── MultiPickBallWindow.java    # 插件自有的 UI 类
└── build.bat                   # 一键构建并复制到 extensions/
```

`build.bat` 要点：

```bat
javac -encoding UTF-8 -cp ..\..\RandomNamePicker.jar -d classes *.java
echo Plugin-Class: MultiBallPlugin> manifest.txt
jar cfm MultiBallPlugin.jar manifest.txt -C classes .
copy /y MultiBallPlugin.jar ..\..\extensions\MultiBallPlugin.jar
```

## 4. 高级主题

### 4.1 接管悬浮球抽取（MultiBallPlugin 的做法）

```java
context.registerFloatingBallPickHandler((ball, scheme, names, count) -> {
    if (count <= 1) {
        return false;                     // 单人抽取交给主程序默认处理
    }
    // 接管：主球滚动 → 去重抽取 → 弹出多球动画
    List<String> winners = NamePickerApp.pickDistinct(names, count, new java.security.SecureRandom());
    // 用 ball.setDisplayText(...) 做滚动效果，再创建自己的动画窗口
    return true;                          // 告知主程序已接管
});
```

### 4.2 使用 UI 篡改接口改造界面

```java
context.setMainDisplayText("插件已就绪！");        // 改显示文本
context.registerMainComponent(new JLabel("插件注入")); // 注入组件
JMenu menu = new JMenu("我的插件");
context.addMainMenu(menu);                          // 注入菜单
NamePickerApp app = context.getMainApp();           // 高级入口：自由改造
```

### 4.3 插件自带设置项

推荐做法：注册设置面板 + 独立配置文件（不要写入主程序配置，便于插件卸载清理）：

```java
JSlider slider = new JSlider(50, 255, 200);
slider.addChangeListener(e -> saveOwnConfig(slider.getValue()));
JPanel panel = new JPanel(new FlowLayout());
panel.add(new JLabel("透明度："));
panel.add(slider);
context.registerSettingsPanel("我的插件设置", panel);
```

配置文件放在 `data/<插件名>_plugin.properties`（参照 MultiBallPlugin）。

### 4.4 依赖第三方库（PenPlugin 的做法）

插件系统只加载**单个 JAR**，因此依赖库需要打 **fat JAR**：

```bat
:: 1) 解压依赖进 classes
jar xf lib\jna-5.14.0.jar -C classes
:: 2) 编译插件（classpath 加依赖）
javac -cp ..\..\RandomNamePicker.jar;lib\jna-5.14.0.jar -d classes *.java
:: 3) 整体打包
jar cfm PenPlugin.jar manifest.txt -C classes .
```

### 4.5 原生能力（PenPlugin 的做法）

- 用 JNA 替换窗口过程（`SetWindowLongPtr(GWL_WNDPROC, callback)`）拦截 `WM_POINTER*`，
  可获得笔/触摸/鼠标原始输入、触点面积、压感；
- `Native.getComponentPointer(window)` 可取得 Swing 窗口的 HWND；
- **必须保持回调对象的强引用**，防止被 GC 后崩溃；
- 原生不可用时提供 AWT 事件降级路径（PenOverlayWindow 已实现）。

## 5. 调试与排错

| 现象 | 排查 |
| --- | --- |
| 插件没加载 | 看 `log/Modifylog.txt` 中 `PLUGIN_*` 记录：JAR 是否在 `extensions/`；清单是否含 `Plugin-Class`；类是否实现 `Plugin` |
| `IllegalAccessError` | 插件引用了主程序**非 public** 的类（如早期版本的 `Scheme`）；只能使用公开 API |
| `NoClassDefFoundError` | 插件依赖未打入 fat JAR |
| 插件崩溃影响主程序？ | 不会：加载与扩展点回调均被 try/catch 隔离 |

## 6. 发布插件

1. 构建 fat JAR（含依赖）；
2. 复制到用户机器的 `extensions/` 目录；
3. （可选）在 README/文档中说明插件名称、版本、扩展点与配置项；
4. 删除 JAR 即卸载插件。
