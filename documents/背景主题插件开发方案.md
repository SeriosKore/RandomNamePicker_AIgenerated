> 本插件与既有"正计时子球"插件相互独立、可共存；产物为独立插件 jar，部署到运行目录 `plugins/`。

## 0. 需求复述（含已拍板决策）

用户可为**各窗口**导入照片作为背景（主题多样化）；**窗口尺寸变化时背景图片随之调整**（缩放/裁切按尺寸重排、即时重绘）。

**已拍板决策（D 系列见 §8）：**

| # | 决策 |
|---|---|
| D1 | 应用范围：**全局背景图**（所有目标窗口兜底）+ **按窗口类别单独指定**图片（未指定者继承全局图） |
| D2 | 适配模式（每图可设）：**居中 / 适应(完整显示) / 填充(裁切填满，默认) / 拉伸 / 自由裁切(手动裁剪框)** |
| D3 | **自由裁切 = 手动裁剪框**：设置页对某窗口/图打开预览，拖拽缩放裁剪框，仅对该(类别,图片)生效 |
| D4 | 可读性方案：**背景图先按“遮罩值”做半透明白混合再显示**（默认 40，滑杆 0–180，0=关闭）；不做内容层之上的遮罩层（避免拦截鼠标/控件事件，见 §4） |
| D5 | 默认值：适配模式默认=**填充**；遮罩默认=**40**；未导入任何图且未启用 → **窗口零变化** |
| D6 | 卸载/删除插件 → **全部窗口还原默认外观**（运行时装饰随 onUnload 清理） |
| D7 | 豁免窗口（不贴图）：悬浮球（FloatingBall）、计时子球（TimerBall，属既有插件）、托盘；JOptionPane 消息弹窗默认豁免（如需可后续放开） |
| D8 | 图片导入即**复制**进插件自有目录 `data/<插件>/images/`（不引用原路径，防源文件失效）；配置自持独立 properties 文件，不触碰宿主 `data/config.properties` |

## 1. 可行性结论

**可行，但“背景贴图”只能走与既有插件同族的“运行时观察 + 组件树装饰”路线（宿主零改动），代价与边界如下：**

- 官方插件钩子只有：模式注册、三类菜单、**设置窗"插件"区按钮**（`addUiAction(UiZone.SETTINGS_WINDOW)`）、数据/日志服务。→ 设置入口有官方位（新增"背景主题"按钮），但**没有官方“换肤/背景”槽**。
- Swing 亦无跨窗口换肤 API 可免改源码地替换各面板绘制。
- 可行做法（§4 引擎）：全局侦测窗口 → 向每个目标窗口的内容层**之下**垫一个自绘背景组件；把“要透出图片的表面容器”翻为非不透明（递归处理 JPanel 等，**控件区域保留原样**保可读性）；窗口 **resize 时**失效缓存并重算缩放图重绘（满足"窗口变化图片跟着调"）；关窗/卸载时还原。
- 选择"表面透出"路线而非"整窗覆写"：控件（表格/输入框/按钮）区域保持自身底色，文字永远可读、风险最低；整窗沉浸式覆写列为后续可选增强（需逐控件特判，暂不做）。
- 本方案全部新增文件位于插件目录；对宿主的唯一依赖 = 现有 UI 槽 + 运行时窗口结构（失效只影响本功能，不伤宿主，同前两插件口径）。

## 2. 目标窗口与类别

类别用于“按窗口单独指定图”（D1）。初始清单（均为主窗/对话框，运行时按类型识别；列表可随实现微调）：

| 类别（配置键前缀） | 对应宿主窗口 | 说明 |
|---|---|---|
| 主窗口 | `NamePickerApp`（JFrame） | 最大展示面，必支持 |
| 配置名单 | `ConfigWindow` | 含 JTable，表格区保底 |
| 方案管理 | `SchemeManagerDialog` | |
| 数字设置 | `NumberPicker` | |
| 座位设置 | `SeatPicker` | 含网格按钮 |
| 系统设置 | `SettingsWindow` | 本插件按钮所在窗，自身也可被贴图 |
| 其它对话框 | `PasswordDialog / OldPasswordDialog / NewPasswordDialog / ChangePasswordDialog` 等小窗 | 默认并入“其它”，可整类关闭贴图 |
| 豁免（不贴） | FloatingBall、TimerBall、托盘、JOptionPane | 见 D7 |

> 生效规则：某窗口有“该类指定图”用该类图；否则用全局图；全局与类均无图（或总开关关）→ 该窗口零变化。
> 宿主每次打开对话框都是新实例 → 引擎按“窗口实例”即时装饰，无需常驻改造。

## 3. 设置入口与对话框（“背景主题”按钮）

- **入口**：设置窗“插件”区按钮，`ctx.addUiAction(UiZone.SETTINGS_WINDOW, "背景主题", …)` → 打开模态对话框（owner=按钮所在 Window）。
- **对话框内容（全部即时生效并持久化）**：
  1. 顶部：**总开关**（启用背景；默认开）+ **恢复默认**按钮；
  2. **图片库**：`导入照片…`（JFileChooser 多选；jpg/png/bmp/gif；复制进 `data/<插件>/images/`）、缩略图列表、删除选中；
  3. **全局背景行**：全局图片下拉（图库项/无）+ 适配模式下拉（居中/适应/填充/拉伸/自由裁切）+ “裁剪…”按钮（模式=自由裁切时启用预览拖框）；
  4. **每窗口类别行**：同全局行结构（图片下拉含“继承全局”，默认继承）；
  5. **遮罩滑杆** 0–180（默认 40，0=关闭）+ 说明文案；
  6. **预览**：全局行/类行旁缩略预览；自由裁切用大图预览拖拽框。
- 未导入任何图时对话框给出引导文案；此时各窗口零变化（D5）。

## 4. 核心引擎设计（WallpaperEngine，仅 EDT）

1. **侦测与重装饰**：全局 AWT WINDOW 事件 + 低频窗口轮询（约 150–200ms，沿用既有插件先例），识别“目标窗口实例”（新开即处理；插件加载后对已开窗口补扫一次）。豁免列表过滤（D7）。
2. **贴图结构**（每窗口实例一次）：
   - 在该窗口 `rootPane.getLayeredPane()` 的**最底层**加入自绘背景组件（全窗大小、置于内容层之下）；
   - 对内容组件树做**非不透明化白名单**：JPanel/JScrollPane（含 viewport 面板）等纯容器翻 `setOpaque(false)`；JButton/JTable/JTextComponent/滑块等**一律不动**（保样式与可读）；
   - 记录已翻转组件，供还原。
3. **渲染与模式**（背景组件 paint 内按缓存图绘制）：
   - 缓存：`(窗口, 宽高, 图, 模式, 裁剪框) → 缩放后 BufferedImage`；命中直接贴，未命中重算；
   - 模式：居中=原尺寸居中；适应=等比完整显示（留边）；填充=等比裁切填满（默认）；拉伸=非等比铺满；自由裁切=按裁剪框（归一化 x/y/w/h）裁出后缩放填满；
   - **遮罩**：缩放图上先叠加 `半透明白(alpha=遮罩值)` 再绘出——背景压暗泛白、前景文字/控件对比度提升，且无需内容层之上的拦截层（D4，不挡鼠标）。
4. **“窗口变化图片跟着调”**：对每窗口安装 `ComponentListener.componentResized` → 失效尺寸缓存 + `repaint()`；窗口移动不重算（仅重绘）。
5. **还原与清理**：`windowClosed` 移除监听、摘除垫层、恢复 opacity 记录；插件 `onUnload` 遍历仍装饰的窗口执行同一还原并清缓存/停轮询——卸载即还原（D6）。
6. **与既有插件共存**：不触碰 FloatingBall / 计时子球 / 自身计时插件窗口；两插件各自在设置窗各有一个按钮。

## 5. 数据模型与持久化

- 文件：`data/theme_background_plugin.properties`（自持；宿主 config 不动）；图片目录：`data/theme_background_plugin/images/<uuid>.<ext>`。
- 键：`enabled`、`mask`、`globalImageId/globalMode/globalCrop`、`cat.<类别>.imageId/mode/crop`、`crop` 为归一化 `x,y,w,h`。
- 损坏/缺键回退默认；图片文件缺失时该行提示“图片丢失”并回退（全局无则零变化）。

## 6. 插件包结构（examples/plugin-theme/，全部新增）

| 文件 | 职责 |
|---|---|
| `BackgroundThemePlugin.java`（实现 Plugin） | 入口：注册 `SETTINGS_WINDOW`“背景主题”按钮；EDT 装配 Config+Engine；onUnload 全还原 |
| `ThemeConfig.java` | 配置模型 + properties 读写 + 图片目录管理（导入复制/删除/缩略） |
| `WallpaperEngine.java` | §4 引擎：窗口侦测/贴图/resize 重排/还原清理 |
| `ThemeSettingsDialog.java` | §3 对话框（图库/全局与类别行/模式下拉/自由裁切预览/遮罩/恢复默认） |
| `ImageRenderer.java`（或并入 Engine） | 缩放/裁剪/遮罩/缓存工具 |
| `BUILD.txt` | 编译打包安装说明 |

jar 只含插件自身类，禁止打包 `com/randomnamepicker/**`；显示名“背景主题”。

## 7. 构建、部署与验收

构建/部署同前插件：以新版 `out` 为类路径编译 → `jar cf` → 复制 `plugins/` → 重启宿主。
验收清单（人工）：
- [ ] 设置窗“插件”区出现“背景主题”按钮（与“计时子球”并存），点击弹出设置对话框
- [ ] 导入多张照片：复制进 `data/theme_background_plugin/images/`；缩略图列表正确；删除可用
- [ ] 未导入时各窗口零变化；导入并启用后：主窗与各对话框留白区显示背景图，控件区域可读
- [ ] 全局图对未单独指定的类别生效；某类别指定后只影响该类窗口
- [ ] 模式四档+自由裁切均正确：居中/适应(留边)/填充(裁切无白边)/拉伸/手动裁剪框仅作用该类该图
- [ ] **拖动改变窗口大小 → 背景即时按新模式重排、无残留白块**
- [ ] 遮罩 0–180 生效且不拦截鼠标/按钮点击
- [ ] 悬浮球、计时子球、消息弹窗不被贴图；与“正计时子球”插件功能互不干扰
- [ ] 重启后配置与图片保留；删除插件 jar 重启 → 所有窗口还原默认外观，无残留监听/垫层/进程
- [ ] 宿主零改动复核：`src/` 无 diff；本插件仅新增文件与 `plugins/` jar

## 8. 决策记录与风险

决策：D1–D8 见 §0 表；追加：D9 默认豁免 JOptionPane 与悬浮球/子球；D10 遮罩做在背景图内而非内容层之上（不挡事件）；D11 采用“表面透出”路线、整窗覆写留待二期。

| 风险 | 对策 |
|---|---|
| 运行时装饰依赖宿主窗口现行结构 | 与既有插件同族口径：失效仅影响本功能；卸载即还原；文档明示 |
| 表格/文本/按钮区域不透图 | 属于“表面透出”设计选择（保可读）；后续可做整窗覆写增强 |
| 图片大/窗口多导致内存 | 每窗口仅缓存当前尺寸一张缩放图；关窗即释放；导入前限制单文件大小（如 ≤8MB） |
| 遮罩影响可读性判断主观 | 滑杆 0–180 可调，默认 40；预览即时可见 |
| 与计时子球插件竞态（如都装饰设置窗） | 各自按实例装饰、互不重叠；两插件装饰代码互不感知即可共存 |
| 卸载瞬间尚有窗口未还原 | onUnload 遍历全部已装饰窗口还原 + 停轮询/清缓存；进程退出兜底（窗口随进程销毁） |
