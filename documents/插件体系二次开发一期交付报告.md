## 6. 交付后变更记录（托盘菜单 Swing 化）

**问题**：系统托盘图标右键菜单显示中文为方框（一直如此）。
**根因（经两次实测确认）**：托盘菜单是 native AWT `PopupMenu`，Windows 上由系统菜单字体（Segoe UI，不含中文字形）渲染；`MenuItem.setFont()` 对其**不生效**，Java 无法为它指定中文字体 → 必现方框（Swing 界面中文正常是因为 Swing 自行用雅黑绘制）。
**过程**：先尝试“显式 setFont（微软雅黑）”两版均无效 → 判定为平台限制，改走实现替换路线。
**最终方案（用户拍板 A，已验证通过）**：移除 native 托盘菜单；托盘图标**单击/双击**在屏幕右下角唤出 Swing `JPopupMenu`（`Main.buildSwingTrayMenu`：显示/隐藏主窗、显示·隐藏悬浮球、插件项、退出；双击 350ms 去抖；菜单显示中再点图标收起；插件加载后 EDT 整体重建 `refreshTrayMenu`）。交互变化：**托盘右键不再弹菜单**，改为单击/双击唤出。
**影响面**：`main/Main.java`（托盘实现）；`TRAY_MENU` Zone 语义与插件 API 不变（插件托盘项改渲染为 Swing `JMenuItem`，仍防御执行）。
**验证**：用户实机复测通过（菜单中文正常显示）。相关文档（《插件开发文档.md》§5.3/§15.7、README §4.6 等）已同步。
